> 🌿 **丸子的无限进步** · 本技能出自「丸子的无限进步」技能库 — 小红书 / 视频号同名账号

## 核心公式

```
r_d = C(w_d) - I(l_d) x T(slot) x W(weekday) x E(holiday)
```

- `C(w)` 天气中性基数：晴1.00 / 晴间多云0.99 / 多云0.985 / 阴0.895
- `I(l)` 雨强打击（分盘）：流量盘 / 付费盘 / 打蜡 / 雾化
- `T(slot)` 时段：夜间权重更低
- `W(weekday)` 周内：**实测反向**——周末雨打击 < 工作日
- `E(holiday)` 日历：七夕 +8% / 开学 +12% / 中秋 +18%

## 使用前请注意

1. **数据来源**：`tqhb.com` 当前 https 被对端 RST，需用提前抓好的月度页缓存；`open-meteo` API 用 Python `urllib` + 显式禁代理（`ProxyHandler({})`）直连可用，是补段天气首选。
2. **代理**：本机若开 Clash（如 `127.0.0.1:7897`），调 open-meteo 必须禁代理，否则必失败；PowerShell `Invoke-WebRequest` 在本机不可靠，一律用 Python。
3. **依赖**：OCR 取数需 `rapidocr-onnxruntime` + `pillow`；飞书同步需 `lark-cli`（内容走 stdin，勿用 `@file:`）。
4. **路径占位**：SKILL.md 中 `D:\terminal\...\洗车天气分析\...` 为作者本地项目路径，请按你自己的数据目录替换。
5. **V3 参数**随累积数据应定期重校准（满足 ≥90 天新数据 + 回测 r<0.55 + 新门店 三条才重跑）。

## 适用业务

加油站洗车（WashNow 类 20 元/次流水线洗车）、油站运营周报归因。参数基于新乡 18 店 + 上海莲花南路 1 店的实测反推。
